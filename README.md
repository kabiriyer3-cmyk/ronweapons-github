# RoN Weapons (Fabric 1.21.1)

Оружие из Ready or Not в Minecraft: M4A1, Glock 19, Colt Python и дробовик Mossberg 590A1. Модели, руки спецназа,
анимации и звуки из RoN, стрельба хитсканом (у дробовика 8 дробин), магазин показывается полоской прочности,
сменные прицелы и глушители (хранятся на самом предмете), настоящая модель оружия в руках от третьего лица.

**В этом репозитории только код.** Модели, текстуры и анимации Ready or Not сюда не входят и выкладывать их нельзя.
Они собираются у тебя локально из твоей установки RoN в приватный ресурспак `RoN-Weapons-Private.zip`.

## Сборка мода
GitHub Actions собирает jar на каждый push (`.github/workflows/build.yml`). Готовый файл лежит в
**Actions → последний запуск → Artifacts → ronweapons-jar**. Локально: `gradle build` (Gradle 8.14, JDK 21).

## Установка
1. Fabric Loader 0.16.14+ для Minecraft 1.21.1 и Fabric API 0.116.x.
2. `ronweapons-0.1.0.jar` в `.minecraft/mods`.
3. `RoN-Weapons-Private.zip` в `.minecraft/resourcepacks`, включить в «Пакетах ресурсов».
4. В игре: `/give @s ronweapons:m4a1` (или вкладка «Бой» в творческом режиме).

Без приватного ресурспака мод работает, но ствол выглядит как обычный предмет.

## Управление
| Действие | Клавиша |
|---|---|
| Стрелять | ЛКМ |
| Прицелиться | ПКМ (зажать) |
| Перезарядка | R (с патронами: тактическая, пустой магазин: полная) |
| Режим огня авто / одиночный | B |
| Проверить магазин | G |
| Сменить прицел (механика → коллиматоры) | M |
| Надеть / снять глушитель (M4A1, Glock) | N |
| Прервать зарядку дробовика | ЛКМ (дозарядит патрон, который уже в руке) |

Прицелы: M4A1 (EOTech EXPS3, Aimpoint M5B, Micro T-2), Glock 19 (RMR, SRO), Python (Micro T-2).
Клавиши меняются в Настройки → Управление → RoN Weapons.

## Как собрать приватный ресурспак
Нужны: своя копия Ready or Not, .NET 10 SDK, Python 3.10+ с numpy и Pillow.
1. `Mappings.usmap`: запусти RoN с UE4SS, в главном меню нажми Ctrl+Numpad6, закрой игру.
   После каждого обновления RoN это надо повторить.
2. Выгрузка ассетов (только чтение паков):
   ```
   cd tools/ronexport
   dotnet run -c Release -- export ../m4a1_targets.txt "<RoN>/ReadyOrNot/Content/Paks" ../../private/export
   dotnet run -c Release -- export ../arms_targets.txt "<RoN>/ReadyOrNot/Content/Paks" ../../private/export
   ```
3. Сборка пака: `py tools/ronconv/build_pack.py private/export private`
   (с `--install <путь к .minecraft>` сразу положит его в resourcepacks).

`tools/ronconv/rig.py`, `preview.py` и `diag.py` это эталон математики рига на Python: по ним проверено, что руки
держат ствол (расстояние кисти до оружия ~5 см) и дуло смотрит вперёд.

## Как это устроено
- psk/psa из CUE4Parse: правая система координат, Z вверх, сантиметры, персонаж смотрит в -Y, вращения не-корневых
  костей сопряжены (классика ActorX). Все клипы RoN выгружаются как абсолютные позы, даже `add_*`.
- Ствол (кость `J_Gun`) висит на кости рук `weapon_right`. Камера берётся из кости `fp_camera`, так что «game feel»
  движение камеры из анимаций RoN сохраняется.
- Скиннинг на CPU, вывод через entity-слой Minecraft. Между клипами плавные переходы (lerp/nlerp).

## Что пока не сделано
- Положение оружия от третьего лица подбирается в `rig.json` пака: `"tp": {"back": 0.3, "yaw": -17.2, "offset": [x, y, z]}`.
- Оптика с увеличением (ACOG и т.п.) не добавлена, только коллиматоры.
- Остальные стволы: тот же конвейер, нужно добавить цели в `tools/*_targets.txt` и таблицу `ACTIONS` в `build_pack.py`.
